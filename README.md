# 바탕화면 주식 시세 위젯

바탕화면 한구석에 작게 떠서 한국 주식 시세가 계속 갱신되는 위젯입니다.
파이썬 표준 라이브러리만 씁니다 — `pip install` 할 것이 없습니다.

---

## 실행

**`주식 위젯` 바로가기를 더블클릭하세요.**

> `stock_widget.pyw` 를 직접 더블클릭하면 안 됩니다.
> 이 PC에는 `.pyw` 확장자에 파이썬이 연결되어 있지 않아서(설치할 때
> "Associate files with Python" 을 안 켠 상태) Windows가 무엇으로 열지 물어봅니다.
> 바로가기는 파이썬을 직접 가리키므로 그 문제를 우회합니다.

검은 콘솔 창은 뜨지 않습니다. 처음 실행하면 화면 **우상단**에 삼성전자 시세가 나타납니다.

---

## 조작

| 하고 싶은 것 | 방법 |
|---|---|
| 위치 옮기기 | 위젯을 마우스로 끌기 |
| 종목이 뭔지 확인 | 위젯에 마우스를 올리고 0.5초 대기 (툴팁) |
| 설정 | 위젯에 **우클릭** |
| 종료 | 우클릭 → 종료 |

### 우클릭 메뉴

- **표시 항목** — 종목명 / 가격 / 등락률 / 수익률을 각각 켜고 끕니다.
  끈 항목은 자리를 남기지 않고 창이 그만큼 줄어듭니다.
  가격만 켜면 숫자 하나만 남습니다. 이때도 **글자색으로 상승·하락을 알 수 있습니다**
  (빨강 = 상승, 파랑 = 하락).
  전부 끌 수는 없습니다 — 아무것도 안 남기 때문입니다.
- **종목 추가** — 종목명으로 검색합니다. "삼성전자" 라고 치면 됩니다.
- **매수 평단가** — 아래 [수익률](#수익률) 참고
- **가격 알림** — 아래 [가격 알림](#가격-알림) 참고
- **갱신 주기** — 아래 [갱신 주기](#갱신-주기) 참고
- **시세 출처** — 아래 [한국투자증권으로 받기](#한국투자증권으로-받기) 참고
- **종목 삭제** / **투명도** / **글꼴 크기** / **항상 위** / **위치 초기화**

## 종목 추가

**종목명을 그대로 입력하세요.** 코드를 외울 필요 없습니다.

- `삼성전자` → 1건이므로 바로 등록
- `카카오` → 카카오 · 카카오페이 · 카카오뱅크 · 카카오게임즈 중에서 선택
- `현대차` → 현대차증권과 **현대자동차**가 함께 나옵니다.
  KRX 는 법인명(현대자동차)을 쓰고 사람은 통칭(현대차)을 쓰기 때문에,
  글자가 순서대로 들어 있기만 하면 찾아주도록 되어 있습니다.

### ETF / ETN 은 코드로 넣어야 합니다

검색에 쓰는 KRX 상장종목 목록에는 **ETF·ETN이 들어 있지 않습니다.**
다만 시세 조회는 정상 동작하므로 **6자리 코드를 직접 입력**하면 등록됩니다.

| 종목 | 코드 |
|---|---|
| KODEX 200 | `069500` |
| TIGER 미국S&P500 | `360750` |
| KODEX 레버리지 | `122630` |

코드는 네이버 증권에서 종목을 검색하면 이름 옆에 나옵니다.

> 참고: 종목코드가 항상 숫자인 것은 아닙니다. 최근 상장분에는 `0039P0` 같은
> 영숫자 혼합 코드가 있고, 이것도 그대로 입력하면 됩니다.

## 수익률

**우클릭 → 매수 평단가 → 종목**을 고르고 산 가격을 넣으면, 그 종목 줄 끝에
지금 몇 퍼센트 이익인지 손해인지가 괄호로 붙습니다.

```
삼성전자  71,200  ▲1.50%  (+3.21%)
           ─┬──   ─┬───    ─┬─────
            │      │        └ 내 평단 대비 수익률
            │      └ 오늘 등락률 (전일 종가 대비)
            └ 현재가
```

넣는 값은 **총 매수금액이 아니라 1주당 평균 단가**입니다. 증권사 앱의 "평균 단가"
또는 `총 매수금액 ÷ 수량` 입니다. 입력하는 동안 지금 값으로 계산한 수익률이
바로 아래에 나오니, 자릿수를 잘못 넣으면 확인 버튼을 누르기 전에 알 수 있습니다.

**보유 수량은 선택**입니다. 넣으면 위젯에 마우스를 올렸을 때 툴팁에
평가손익이 원화로도 나옵니다.

```
삼성전자 (005930)
평단 69,000원 · 10주
수익률 +3.21% · 평가손익 +22,000원
```

- 평단가를 넣지 않은 종목은 괄호가 아예 붙지 않습니다. 자리를 비워두지 않습니다.
- 평단가를 **비우고 확인**을 누르면 그 종목의 수익률 표시가 꺼집니다.
- 줄 색깔은 **오늘 등락** 기준 그대로입니다. 내 수익률은 괄호 안의 부호로 봅니다
  (오늘 오르는 중이라도 내 평단보다 낮으면 `(-…%)` 입니다).
- 수익률 칸 전체가 필요 없으면 **표시 항목 → 수익률**을 끄면 됩니다. 넣어둔
  평단가는 지워지지 않고, 툴팁에는 계속 나옵니다.
- 종목을 삭제하면 그 종목의 평단가도 함께 지워집니다.

> 세금·수수료는 계산하지 않습니다. 현재가와 평단가만 비교한 단순 수익률입니다.

## 갱신 주기

기본값은 **서버 권장(장중 7초) 고정** 입니다. 우클릭 → **갱신 주기** 에서 5 · 3 · 2 · 1초를
고를 수 있습니다.

### 언제 얼마나 자주 받나

2026년 9월 14일부터 **애프터마켓(오후 4시~8시)** 이 생겼습니다. 이때도 가격이 실제로
움직이기 때문에 위젯은 정규장과 똑같이 갱신하고, **가격 알림도 그대로 갑니다.**

| 시간 | 무슨 시간 | 갱신 |
|---|---|---|
| 09:00~15:30 | 정규장 | 고른 주기 |
| 15:30~16:00 | 시간외종가 (**가격이 종가에 묶여 안 움직임**) | 10초 |
| 16:00~20:00 | **애프터마켓** (가격 움직임) | 고른 주기 |
| 그 외 · 주말 · 휴장일 | 마감 | 60초 |

15:30~16:00만 10초로 느슨하게 둡니다. 이 30분은 값이 종가에서 안 바뀌어서 빨리 물어봐야
얻는 게 없습니다.

> 애프터마켓에서는 ETF·ETN이 거래되지 않습니다. 그 종목들은 이 시간에 값이 안 움직입니다.
> 애프터마켓 종가는 공식 종가로 인정되지 않습니다.

**고른 값이 무슨 뜻인지는 시세를 어디서 받는지에 따라 다릅니다.**

| 시세 출처 | 고른 값의 뜻 | 메뉴 표시 |
|---|---|---|
| 네이버 (기본) | **가장 빠를 때**의 주기. 거래가 멎으면 7초까지 물러납니다 | `최고 1초` |
| [한국투자증권](#한국투자증권으로-받기) | **그대로 그 주기.** 물러나지 않습니다 | `1초 고정` |

바꾼 주기는 **즉시 적용됩니다.** 위젯을 다시 켤 필요가 없습니다.

아래는 네이버로 받을 때의 이야기입니다.

### 고른 값은 "고정 주기"가 아니라 "가장 빠를 때"입니다

주기를 고르면 위젯은 **체결이 실제로 일어날 때만 그 주기로 당기고, 거래가 멎으면
1초씩 물러나 서버 권장값(7초)까지 되돌아갑니다.** 그래서 메뉴에도 `최고 3초` 처럼
적혀 있습니다.

```
11:50:24  +15주     다음 주기 1초
11:50:25  +50주     다음 주기 1초   ← 체결이 이어지는 동안은 최고 속도
11:50:29  체결 없음   다음 주기 2초
11:50:31  체결 없음   다음 주기 3초   ← 멎으면 물러난다
11:50:35  +15주     다음 주기 1초   ← 다시 체결되면 즉시 복귀
```

**고정 주기로 두지 않는 이유는 빈 요청 때문입니다.** 1초 간격으로 20회를 받아보면
체결시각(`localTradedAt`)은 매번 바뀌지만, 그건 요청 시각을 따라올 뿐입니다.
누적 거래량이 실제로 늘어난 것은 20회 중 6회뿐이었고 **나머지 14회는 같은 값을
다시 받은 빈 요청**이었습니다. 종목의 체결 빈도가 상한이지 폴링 주기가 상한이
아닙니다. 그런데 요청 수는 그대로 늘어납니다.

### 고를 때 실제로 늘어나는 요청 수

| 설정 | 장중 하루 요청 수 | |
|---|---|---|
| 서버 권장 7초 고정 | 약 3,300회 | 네이버가 시킨 대로 |
| 최고 5초 | 약 4,000회 | |
| **최고 3초** | 약 6,000~6,700회 | 3초 고정(7,800회)보다 적습니다 |
| 최고 2초 | 약 8,000회 | ⚠ |
| 최고 1초 | 약 11,700회 | ⚠ 1초 고정(23,000회)의 절반이지만 가장 많습니다 |

거래가 활발한 종목일수록 하한에 머무는 시간이 길어 요청이 늘어납니다. 위 수치는
활발한 종목 기준이고, 한산한 종목은 대부분 7초에 머뭅니다.

2초 이하를 고르면 한 번 더 물어봅니다. **차단되면 Yahoo 폴백(15분 지연)으로
떨어집니다.** 네이버는 레이트리밋을 공개하지 않고 응답에 한도 헤더(`X-RateLimit-*`,
`Retry-After`)도 없어서 **차단이 가까워졌는지 미리 알 방법이 없습니다.** `ETag` 도
`Last-Modified` 도 없어 조건부 요청으로 부하를 줄일 수 없고, `Connection: close` 라
연결 재사용도 서버가 거부합니다. 빈 요청을 줄이는 것 말고는 깎을 여지가 없습니다.

**차단 없이 1초를 쓰고 싶다면** 증권사 공식 API 로 갈아타는 것이 정공법입니다.
아래 [한국투자증권으로 받기](#한국투자증권으로-받기)를 보세요.

## 한국투자증권으로 받기

한국투자증권(KIS) Open API 는 **무료 공식 API** 입니다. 연동하면 위젯이 네이버 대신
이쪽으로 받습니다. 달라지는 것은 두 가지입니다.

- **고른 주기가 그대로 적용됩니다.** 1초를 고르면 1초입니다. 물러나지 않고, 2초 이하를
  골라도 경고하지 않습니다 — 한도(실전 초당 20건)가 공개돼 있어 몰래 두드리는 것이
  아니기 때문입니다.
- **차단 걱정이 없습니다.** 인증된 내 앱키로 내 한도를 쓰는 것입니다.

시세의 정확도는 네이버와 같습니다. **둘 다 지연 없는 실시간 가격입니다.**
15분 지연은 Yahoo 폴백일 때뿐이고, 그때만 가격 옆에 `*` 가 붙습니다.

### 준비 (한 번만)

1. [apiportal.koreainvestment.com](https://apiportal.koreainvestment.com) 에서
   **KIS Developers 신청** → 계좌 등록
2. **My App** 에서 앱을 만들면 **APP KEY** 와 **APP SECRET** 이 나옵니다
3. 위젯 폴더의 **`.env`** 파일을 메모장으로 열어 두 값을 붙여넣고 저장합니다

```
KIS_APP_KEY=여기에앱키를붙여넣으세요
KIS_APP_SECRET=여기에앱시크릿을붙여넣으세요
```

`=` 뒤의 한글 안내문을 지우고 그 자리에 넣으면 됩니다. 따옴표는 필요 없습니다.
**저장하면 다음 갱신(1초 뒤)부터 적용됩니다. 위젯을 다시 켜지 않아도 됩니다.**

파일을 못 찾겠으면 우클릭 → **시세 출처** → **.env 파일 열기…** 를 쓰세요.
없으면 만들어서 열어 줍니다.

앱시크릿은 180자가 넘습니다. 손으로 치지 말고 복사해서 붙여넣으세요.
안내문(한글)을 지우지 않으면 "아직 안 적었다"로 보고 연동하지 않습니다.

**실전투자 계좌용 앱키여야 합니다.** 모의투자 키는 동작하지 않습니다.

`.env` 대신 우클릭 → **시세 출처** → **한국투자증권 연동…** 에서 입력창에 붙여넣어도
됩니다. 단 `.env` 에 값이 있으면 **`.env` 가 우선**이라 입력창은 나오지 않습니다.

### 알아둘 것

- **접근토큰을 발급할 때마다 휴대폰으로 알림톡이 한 통 옵니다.** 정상입니다.
  토큰은 하루짜리라서 위젯이 알아서 하루 한 번만 받습니다. 위젯을 하루에 열 번 켜도
  발급은 한 번입니다.
- 연동이 잘 안 되면 위젯은 **조용히 네이버로 돌아갑니다.** 시세가 멎지는 않습니다.
  그 사실은 종목 위에 마우스를 올리면(`⚠ KIS 조회 실패`), 그리고 우클릭 →
  **시세 출처** 에서 볼 수 있습니다.
- 지금 어디서 받고 있는지는 우클릭 → **시세 출처** 맨 윗줄에 나옵니다.
- **연동 해제** 하면 앱키와 토큰을 지우고 네이버로 돌아갑니다.

### 앱키는 어디에 저장되나요

적어 넣은 `.env`, 그리고 위젯이 발급받은 토큰은 `kis_token.json` 입니다.
**둘 다 비밀번호나 다름없습니다.** 남에게 보내거나 폴더째 공유하지 마세요.
실수로 노출됐다면 KIS Developers 에서 앱을 삭제하고 새로 만드세요.

## 가격 알림

조건이 맞으면 **화면 우하단에 팝업**이 뜨고, 카카오톡을 연동해 두었으면
**폰으로 "나에게 보내기" 메시지**가 옵니다. 알림을 눌러 열면 네이버 증권의
해당 종목 페이지로 바로 갑니다.

우클릭 → **가격 알림** 에서 종목을 고르면 세 가지를 설정할 수 있습니다.

| 조건 | 뜻 | 다시 울리나 |
|---|---|---|
| **이 값 이상이 되면** | 72,000원을 넘으면 | **아니요.** 한 번 울리면 그 조건은 저절로 꺼집니다 |
| **이 값 이하가 되면** | 65,000원 밑으로 내려가면 | **아니요.** 위와 같습니다 |
| **급변동 감지** | 짧은 시간에 크게 움직이면 | **종목당 하루 한 번**까지만 |
| **상·하한가 도달·풀림** | 상한가에 붙거나 풀리면 | **바뀔 때마다.** 하루에 여러 번 올 수 있습니다 |

목표가는 **한 번 쓰고 없어지는 알림**입니다. 울린 뒤 메뉴를 열어보면 그 자리가
비어 있습니다. 계속 감시하고 싶으면 다시 설정하면 됩니다.

**이미 도달한 값은 넣을 수 없습니다.** 현재가가 70,000원인데 "65,000원 이상"을
넣으면 다음 갱신에 곧바로 울릴 텐데, 그건 원하는 바가 아니기 때문입니다.

### 상·하한가

상한가에 붙으면 **`🚀 상한가 도달`**, 풀리면 **`🔓 상한가 풀림`** 이 옵니다.
하한가도 같은 규칙으로 옵니다 (`🧊` / `🔓`). 하루에 잠겼다 풀렸다를 반복하면
그때마다 옵니다 — 그 오감 자체가 알고 싶은 사건이기 때문입니다.

**등락률로 짐작하지 않고 거래소가 붙인 상한/하한 표시를 그대로 씁니다.**
가격제한폭이 늘 ±30%인 것은 아니어서(신규상장 첫날, 정리매매 종목 등)
"30% 근처면 상한가"로 판정하면 틀립니다. 실제로 이 위젯을 만드는 동안
**+62%인데 상한가가 아닌 종목**이 잡혀 있었습니다.

헷갈릴 만한 두 가지를 막아두었습니다.

- **알림을 켤 때 이미 상한가라면 울리지 않습니다.** 첫 관측은 기준점으로만 씁니다
- **상한가로 마감한 다음 날 아침에 "풀림"이 오지 않습니다.**
  장이 닫히면 기준점을 버리고, 다시 열릴 때 처음부터 셉니다

호가가 한 틱 오가며 도배하는 것을 막으려고, 바뀐 상태가 **연속 두 번 확인될 때**
울립니다. 장중 갱신이 7초 간격이니 실제로는 10초쯤 늦게 옵니다.
급변동과 마찬가지로 **Yahoo 폴백 중에는 판정하지 않습니다** — 지연 시세에는
상한/하한 표시가 없어서, 모르는 것을 "풀렸다"로 지어내게 되기 때문입니다.

### 급변동 기준

기본값은 **5분 안에 2%** 입니다. 우클릭 → 가격 알림 → **급변동 기준…** 에서
`10, 3` 처럼 입력하면 "10분 안에 3%"로 바뀝니다. 모든 종목에 함께 적용됩니다.

급변동은 **장중에만** 판정합니다. 다음 경우에는 값이 크게 튀어도 울리지 않습니다.

- 장이 닫혀 있을 때 (종가가 고정이라 판정할 값이 없습니다)
- Yahoo 폴백으로 넘어갔을 때 (15분 지연 시세로 "지금 급변동 중"을 말할 수 없습니다)
- 시세가 1분 이상 끊겼다가 돌아온 직후 (절전에서 깨어났을 때 그렇습니다.
  이걸 안 막으면 "5분 만에 3% 급등"으로 잘못 읽습니다)

## 카카오톡으로 받기

카카오톡 **나에게 보내기**를 씁니다. 무료이고 심사도 없지만, **처음 한 번은
카카오 개발자 앱을 직접 만들어야 합니다** (10분 정도). 대신 해드릴 수 없는
부분입니다 — 본인 인증과 약관 동의가 필요하기 때문입니다.

우클릭 → 가격 알림 → **카카오톡 연동…** 을 열면 아래 순서가 그대로 적혀 있고,
Redirect URI 복사 버튼과 개발자 사이트 바로가기도 그 안에 있습니다.

1. [developers.kakao.com](https://developers.kakao.com/console/app) → 내 애플리케이션 → **애플리케이션 추가하기**
2. 앱 설정 → 앱 키 → **REST API 키** 복사
3. 제품 설정 → 카카오 로그인 → **활성화 상태 ON**
4. 같은 화면의 **Redirect URI** 에 `http://localhost:8321/callback` 등록
5. 제품 설정 → 카카오 로그인 → 동의항목 → **카카오톡 메시지 전송**을 선택 동의로

REST API 키를 붙여넣고 **연동 시작**을 누르면 브라우저가 열립니다. 동의를 마치면
위젯이 알아서 이어받고 **테스트 메시지를 보냅니다.** 폰에 도착하면 끝난 것입니다.

> **Client Secret** 칸은 대개 비워두면 됩니다. 앱에서 켜두었다면 그 값을 넣으세요.
>
> 브라우저가 안 열리거나 8321 포트가 막혀 있으면, 마법사 아래쪽에
> **브라우저 주소창의 주소를 통째로 붙여넣는 칸**이 나타납니다.

### 브라우저에 오류 화면이 뜨면

카카오가 거절하면 위젯으로 되돌아오지 않으므로, **위젯은 아무것도 모른 채
2분을 기다립니다.** 브라우저에 뜬 코드를 보고 아래에서 찾으세요.

| 코드 | 무슨 뜻인가 | 어디를 고치나 |
|---|---|---|
| `KOE205` | 동의항목 **'카카오톡 메시지 전송'** 이 아직 꺼져 있습니다 | 위 **5번** — 카카오 로그인 → 동의항목 → **선택 동의**로 설정 |
| `KOE006` | Redirect URI 가 등록되지 않았습니다 | 위 **4번** |
| `KOE101` | REST API 키가 잘못됐습니다 | 위 **2번** — 키를 다시 복사 |
| `KOE010` | Client Secret 이 켜져 있는데 값이 비었습니다 | 마법사의 Client Secret 칸 |
| `KOE320` | 인가 코드를 이미 썼습니다 | **연동 시작**을 다시 누르세요 |

고친 뒤 마법사에서 **연동 시작**을 다시 누르면 됩니다. 위젯을 껐다 켤 필요는 없습니다.

### 연동은 알아서 유지됩니다

카카오 토큰은 주기적으로 저절로 갱신됩니다. 위젯을 평소처럼 쓰면 다시 연동할 일이
없습니다. 다만 **두 달 넘게 한 번도 안 켜면** 갱신 권한이 만료되어 재연동이 필요합니다.

연동이 잘 되어 있을 때 **카카오톡 연동** 을 다시 누르면 마법사가 열리는 대신
**"이미 연동되어 있습니다"** 와 연동한 날짜를 먼저 알려줍니다. 거기서 [아니요]를
누르면 아무것도 바뀌지 않습니다. 잘 되는지 확인만 하고 싶으면
**테스트 메시지 보내기** 를 쓰세요.

연동이 끊기면 위젯 툴팁에 **⚠ 카카오 연동 끊김** 이 뜨고, 알림이 오면 화면 팝업으로
"카카오톡 전송 실패"를 함께 알립니다. **화면 알림은 카카오와 무관하게 항상 뜹니다** —
연동이 끊겨도 PC 앞에 있으면 놓치지 않습니다.

무슨 일이 있었는지는 **`alerts.log`** 에 한 줄씩 남습니다.

## 창을 잃어버렸을 때

이 위젯은 작업표시줄과 Alt+Tab에 나타나지 않습니다. 그래서 화면 밖으로 나가면
되찾을 방법이 없어지는데, 그런 일이 없도록 네 겹으로 막아두었습니다.

1. 드래그로 화면 밖까지 끌어도 **일부(가로 60px)는 항상 화면에 남습니다**
2. 시작할 때 저장된 좌표가 화면 밖이면 무시하고 우상단에 띄웁니다
3. 실행 중에도 5초마다 확인해서, 모니터를 뽑는 등으로 위젯이 화면 밖에 남으면
   **자동으로 주 모니터로 돌아옵니다**
4. 그래도 안 되면 **`위치 초기화.bat`** 을 더블클릭하세요

`위치 초기화.bat` 은 위젯을 하나 더 띄웁니다. 위젯이 두 개 겹쳐 보이면
둘 중 하나를 우클릭해서 종료하면 됩니다.

## 파일

| 파일 | 설명 |
|---|---|
| `stock_widget.pyw` | 본체 |
| `kakao.py` | 카카오톡 전송 (본체가 불러 씁니다) |
| `kis.py` | 한국투자증권 시세 조회 (본체가 불러 씁니다) |
| `CLAUDE.md` | 코드를 고칠 때 읽는 설계 메모 (동작에는 영향 없음) |
| `주식 위젯.lnk` | 실행용 바로가기 |
| `위치 초기화.bat` | 창을 잃어버렸을 때 복구 |
| `config.json` | 설정 (자동 생성·자동 저장) |
| `stocks.json` | 종목 검색용 캐시 (자동 생성, 30일마다 갱신) |
| `kakao_token.json` | **카카오 토큰 — 남에게 보여주지 마세요** (자동 생성) |
| `.env` | **KIS 앱키 — 남에게 보여주지 마세요** (직접 적는 파일) |
| `kis_token.json` | **KIS 토큰 — 남에게 보여주지 마세요** (자동 생성) |
| `alert_state.json` | 급변동을 오늘 이미 보냈는지 (자동 생성) |
| `alerts.log` | 알림 발동·전송 기록 (자동 생성) |

`config.json` 을 직접 고쳐도 됩니다. 형식이 깨지면 위젯이 조용히 안 뜨는 대신
**어디가 잘못됐는지 알려주고**, 원본을 `config.json.bak` 으로 보관한 뒤
기본값으로 시작할지 물어봅니다. 알림 설정은 이렇게 들어갑니다.

```json
"alerts": {
  "005930": { "above": 72000, "below": null, "burst": true, "limit": true }
},
"burst": { "window_sec": 300, "threshold_pct": 2.0 },
"holdings": {
  "005930": { "cost": 69000, "qty": 10 }
}
```

`holdings` 는 매수 평단가입니다. `qty` 는 없어도 되고(`null`), 평단가만 적고
싶으면 `"005930": 69000` 처럼 숫자 하나만 써도 읽습니다.

**`kakao_token.json` 은 계정 자격증명입니다.** 이 파일을 가진 사람은 당신의
카카오톡으로 메시지를 보낼 수 있습니다. 폴더를 통째로 공유하거나 백업할 때
빼세요. 지우면 연동만 풀리고 나머지 설정은 그대로입니다.
(우클릭 → 가격 알림 → **카카오톡 연동 해제** 로도 지울 수 있습니다.)

**`.env` 와 `kis_token.json` 도 마찬가지입니다.** 한국투자증권 앱키와 앱시크릿이
들어 있습니다. 노출됐다면 KIS Developers 에서 앱을 삭제하고 새로 만드세요.
연동을 끊으려면 `.env` 의 두 줄을 지우고 `kis_token.json` 을 삭제하면 됩니다.

## 알아둘 것

**시세는 네이버 금융에서 가져옵니다** (지연 없는 실시간, 장중 7초마다 갱신).
장이 닫혀 있으면 60초마다 확인합니다.

**네이버가 실패하면 Yahoo Finance로 자동 전환**되는데, Yahoo의 한국 주식은
**15분 지연 시세**입니다. 이때는 가격 옆에 **`*`** 가 붙고, 마우스를 올리면
툴팁에 `Yahoo 폴백 · 15분 지연 시세` 라고 나옵니다.

**숫자가 회색으로 변하면 값이 오래된 것입니다.** 네트워크가 끊기거나 절전에서
막 돌아왔을 때 그렇습니다. 마지막 숫자를 지우지 않고 남겨두되, 그게 지금 값이
아니라는 것을 색으로 알립니다. 연결이 돌아오면 자동으로 원래 색으로 바뀝니다.

> 두 시세 출처 모두 공개된 웹 API를 쓰는 것이라 언제든 바뀌거나 막힐 수 있습니다.
> **투자 판단에 쓸 값으로 신뢰하지 마세요.** 정확한 시세는 증권사 HTS/MTS를 보십시오.

**알림도 같은 값을 씁니다.** 이 경고가 알림에 그대로 적용됩니다 —
알림이 안 왔다고 그 일이 없었다는 뜻이 아니고, 알림이 왔다고 그 가격이 정확하다는
뜻도 아닙니다. **매매 트리거로 쓰지 마세요.** PC가 꺼져 있거나 절전 중이면
알림은 아예 오지 않습니다.
